# DEC-0003 — единый раскрой
Осевая длина задаёт трассу; straightLayout вычитает плечи поворотов и формирует детали и модульные стыки. Рисунок и BOM используют одни данные, стоимость прямых деталей — straightLen. Сохранённый формат проекта не изменён. Решение пользователя: исправить неодинаковые соединители на одинаковых участках. Проверки19 PASS; UI fixture PASS. Короткие остатки и полный комплект соединений требуют следующей проверки.
Дополнение2026-10-04: connectionLayout формирует список всех существующих стыков для draw/BOM; схема корпуса100мм условная. Отрисовка границ детализации не подтверждает каталожную длину подключения; FE/FET остаются следующим этапом. Объяснение осевых размеров обязательно в UI.

2026-10-05: короткий остаток перераспределяется из предыдущих деталей до450мм только при общей осуществимости, модуле450–3000мм и шаге10мм. Нельзя округлять длину трассы или скрывать невозможный раскрой.450 — консервативный предел, конфликтCu400/450 остаётся. Пример3100→2650+450;6500осевой с плечом450→3000+2600+450, стыки3000/5600.25целевых проверок PASS; UIотдельно не проверен в этом шаге.
