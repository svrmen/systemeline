# DEC-0003 — единый раскрой
Осевая длина задаёт трассу; straightLayout вычитает плечи поворотов и формирует детали и модульные стыки. Рисунок и BOM используют одни данные, стоимость прямых деталей — straightLen. Сохранённый формат проекта не изменён. Решение пользователя: исправить неодинаковые соединители на одинаковых участках. Проверки19 PASS; UI fixture PASS.
