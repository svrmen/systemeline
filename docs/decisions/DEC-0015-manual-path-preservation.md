# DEC-0015 — сохранить ручной путь и разрешить удаление объектов

ACTIVE, 2026-10-06. Последнее прямое решение пользователя: нарисованная трасса 15 м не должна становиться другим проектом после «Построить»; связанный объект должен удаляться, в том числе после очистки пути. ADDITION_TO_CURRENT_TASK, NOW 7. Отменяет семантику кнопки и запрет удаления из DEC-0012, остальные правила размещения и колонн действуют.

- Непустой путь: основное действие «Подключить мой путь» сохраняет все направления/длины, мировые точки начала/конца, размеры и выноски. Выбранные ТР/НКУ размещаются так, чтобы условный контакт совпал с концом пути, с учётом выбранной колонны. Режим — manual; производится расчёт без замены геометрии.
- Общий объект другой трассы не переносится при подключении. Если совпадение точки требует такого переноса, вся операция отклоняется с указанием связанных линий. Не подгонять другие трассы молча.
- Пустой путь: «Создать между объектами» строит auto между выбранными объектами. Для замены непустого пути отдельный расчёт показывает старую/новую длину, направления/длины участков и кнопку применения. Несвежий предпросмотр не применяется.
- Удаление объекта снимает его привязки во всех трассах. Все участки, мировое начало (включая c5), размеры и выноски сохраняются. Затронутые маршруты переходят в manual. Режим NONE не рисует выдуманный корпус и не считает его FE/FET; неизвестное подключение не заменяется заглушкой.
- Очистка выбранного пути не сбрасывает электрические параметры и оборудование. Сама очистка обратима; удаление оборудования — отдельное действие на его вкладке.
- Перед подключением, автоматическим построением/заменой, удалением и очисткой валидируются весь проект и результат; резервная копия сохраняется в ключе основного namespace + .equipmentUndo. Не менять рабочую сцену при отказе записи. Отмена последнего такого действия сохраняется после reload, но блокируется при последующих правках модели/метаданных. После возврата запись расходуется. Это один последний шаг, не полная история проекта.
- Сохранённые проекты v6/v5/v4/v3 при загрузке не перемещаются и не очищаются. Данные ранее уже заменённого пути не гарантированно доступны: прежняя операция не делала резервной копии. Новая копия защищает новые действия.
- Исходное отображение прямых, синих углов и зелёных стыков сохраняется. Реальные FE/FET, V/VS, монтаж IP65, коллизии и внешняя многотрассовая CAD-печать остаются открытыми.

Проверки: 11 целевых, 77 регрессионных с реальным тарифом, 5 запуска и 3 обновления страниц — 96 PASS. UI: ручные 1500+10000+2500+1000=15000 мм; подключение, предпросмотр 16000 мм без изменения, явная замена/отмена после reload, очистка/отмена, удаление НКУ без изменения пути/отмена после reload. ISO просмотрен; ошибок JavaScript нет.
