# DEC-0014 — согласованная загрузка и проверка запуска

ACTIVE, 2026-10-06. Прямое решение пользователя: нельзя создать трассу, проверить и исправить. ADDITION_TO_CURRENT_TASK: P0 внутри NOW 7. DEC-0012/0013 действуют.

- Причина воспроизведена: старый HTML без nku-columns.js загружал обновлённый routes.js. resize → draw → installRoute обращался к emptyPorts до заполнения списков и назначения кнопок; получался пустой экран как на скриншоте.
- Все шесть локальных ресурсов в index.html используют один revision-параметр. При изменении контракта HTML/модулей revision меняется одновременно. Новая ссылка на основной HTML также содержит build-параметр и использует прежнее хранилище того же origin.
- Новый routes.js распознаёт старую форму и показывает сообщение с «Обновить приложение». Ошибка до завершения запуска тоже показывает восстановление. Ссылка меняет только параметры URL и содержит отдельный refresh; проект и тариф не очищаются. Ошибки восстановления сохранения имеют собственный прежний механизм защиты.
- Приёмка включает запуск с пустого проекта и с сохранённым v5, порядок загрузки скриптов из настоящего HTML, назначение кнопки добавления и построение линий. Проверочная страница с готовым примером не заменяет эту проверку.
- Последующий скриншот подтвердил, что открывался физически устаревший файл .qa/visual.html: простая смена query не обновляла его содержимое. visual/joints уже имели основные ключи сохранения, поэтому теперь переходят в актуальный корень того же origin. Отдельные equipment/multiple-routes/columns генерируются из текущего index.html, сохраняя namespace и исходный пример. tools/refresh-preview-pages.py выполняется перед локальной UI-приёмкой после изменений; пользовательские сохранения не очищаются.

Проверено: 5 новых тестов запуска + 77 текущей регрессии, включая реальный тариф. В браузере старая форма/новые скрипты воспроизведены, ссылка восстановления сработала. С нуля кнопками созданы четыре объекта, пять колонн НКУ, две линии ТР → НКУ и связь из пятой; reload сохранил три линии. Основная страница с build-параметром запущена без ошибок; данные не редактировались. Нативный Chrome не управлялся: пользователь открывает новую ссылку сам.
Ещё 3 теста генерации страниц PASS. Реальная старая visual-ссылка перешла в корень без ошибок; отдельные equipment/multiple-routes открылись с тремя сохранёнными трассами и новыми полями колонн. Всего 85 проверок.
