# DEC-0011 — несколько трасс

ACTIVE, 2026-10-05. Последнее прямое решение пользователя: перейти к следующему шагу, оставшиеся ошибки предыдущего этапа исправлять по результатам проверки. Пункт 7 получает приоритет; внешняя приёмка пункта 6 остаётся открытой.

- До 20 трасс в одном проекте. Каждая имеет стабильный ID, имя, участки, расчёт, модуль, параметры B, выноски, положения размеров и координаты нижнего угла начального оборудования. Метаданные и тариф общие.
- Используется существующая геометрия B. Временный контекст трассы всегда восстанавливает модель, параметры формы и кеш габаритов через finally; автосохранение внутри временного контекста запрещено.
- Общий вид и область спецификации выбираются отдельно. PNG/DXF показывают выбранный вид; PDF строит виды для своей области спецификации. CAD содержит размеры всех показанных трасс на отдельном слое. В интерфейсе и растровых видах размеры выбранной трассы — исходный режим; все размеры включаются отдельно.
- Копия сохраняет геометрию и параметры, смещается на 4000 мм по Y; выноски и позиции размеров создаются отдельно. Смещение — удобство размещения, не инженерная норма. Координаты доступны для правки.
- Новая НКУ → НКУ при наличии двух трасс к НКУ соединяет их конечные точки по осям X/Y/Z. Используются первые две непустые трассы в списке. После создания привязки статические; перемещение источников не меняет связь автоматически. Путь, исполнение и коллизии требуют проверки.
- Общая калькуляция группируется по точному артикулу и единице. Неподтверждённые артикулы дополнительно разделяются по исполнению/назначению. Итог — сумма объединённых строк с округлением до копейки; неизвестная цена не становится нулём.
- Разбиение должно быть рассчитано у всех непустых трасс области перед XLSX/PDF/CSV. Раскрой экспорта содержит имя трассы и артикул; одинаковые длины разных исполнений не теряют принадлежность.
- Проект v4 записывается в BUS_PROJECT_V4. Старый BUS_STATE_V3 читается только при отсутствии нового, сохраняется без изменений. Это защищает новый проект от старых открытых вкладок. Проверяется весь набор до применения; повреждение любой трассы блокирует автоперезапись.
- Очистка относится к выбранной трассе; прочие трассы, общие метаданные и тариф сохраняются.
- Существующие ограничения FE/FET, опор, IP-комплектности и источников не сняты многотрассовой моделью. Общий чертёж не является проверкой электрической топологии.
