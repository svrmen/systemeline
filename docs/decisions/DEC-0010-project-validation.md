# DEC-0010 — ввод и восстановление проекта

ACTIVE, 2026-10-05. Пункт 6 согласованного плана; внешний вид и прежние решения по геометрии сохраняются.

- Изменение максимальной длины прямой секции сразу обновляет модель, раскрой, спецификацию и сохранение. Допустимый ввод 400–3000 мм с шагом 10 мм. Это предел интерфейса; противоречие каталога Cu400/450 и допустимость каждой заказной детали проверяются отдельно.
- Временный неверный ввод не заменяет последнюю корректную модель; пояснение показывает используемое значение. Неверный снимок проекта не сохраняется. Габариты оборудования при неверном вводе используют последние корректные значения с предупреждением.
- Новая/редактируемая осевая длина — конечное безопасное целое ≥400 мм. Старые дробные длины сохраняются без битового усечения, остаются предупреждения о некратной 10 мм прямой детали.
- Снимок проекта полностью проверяется до изменения состояния. Совместимые старые поля имеют явные значения по умолчанию. Старый конфликт module/ui.moduleLen разрешается в пользу сохранённого видимого поля с пересчётом.
- При повреждении данных автосохранение блокируется, оригинал доступен для скачивания. Только явный «Сброс» создаёт новый проект; сначала сохраняется отдельная резервная копия. Если оригинал прочитать/скопировать нельзя, сброс не выполняется.
- Отказ записи показывается пользователю; кнопка метаданных не сообщает об успешном сохранении при отказе.
- Недоступный номинал при смене материала объявляется явно; сообщение снимается после явного выбора нового номинала.

Проверки: 42 PASS и браузерная приёмка (docs/acceptance-2026-10-05.md). Chrome и инженерные ограничения не объявляются закрытыми.
Урок: сохранение должно проверять целостный снимок до применения; одна проверка массива участков не защищает метаданные, параметры и позиции выносок. Изменение поля без синхронизации модели создаёт ложную спецификацию.
