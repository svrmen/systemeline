# DEC-0016 — вид сверху без отражения

ACTIVE, 2026-10-06. Прямое решение пользователя: вид сверху выглядит зеркальным относительно исходной изометрии. ADDITION_TO_CURRENT_TASK, NOW 7; не отменяет стыковку колонн из DEC-0013 и сохранение ручного пути из DEC-0015.

- Исходный ISO остаётся `[(X−Y)cos30°, (X+Y)sin30°−Z]`. TOP — `[X,Y]`: +X вправо, +Y вниз экрана. При переходе меняется ракурс, ориентация плоскости не отражается. FRONT/BACK/LEFT/RIGHT не меняются.
- Перенос/размещение оборудования и hit testing в TOP используют ту же пару X/Y; экранное движение вниз увеличивает мировой Y. Отметка Z сохраняется. Все мировые позиции, направления, длины и расчёт сохраняются при переключении вида.
- Выноски хранят проектные координаты проекции отдельно для каждого вида. Для старых v3/v4/v5/v6 при валидации клона меняются только `TOP.ay/by → −ay/by`, включая каждую трассу и доступную историю отмены. Экранные отступы размеров остаются прежними. Повторное чтение v7 ничего не переворачивает.
- Новый снимок v7 требует `topViewRevision:2` и хранится в BUS_PROJECT_V7; читается первым, затем v6/v5/v4/v3. Старые ключи не записываются. Неизвестная версия/испорченный флаг или колонки блокируют применение и автосохранение. Сохраняемая доступная отмена из старого namespace переносится до первого сохранения v7.
- CAD остаётся 2D-проекцией выбранного вида: для вывода применяется общий переход от экранного Y вниз к CAD Y вверх. Геометрия, размеры и выноски согласованы с экраном; мировые X/Y/Z остаются в атрибутах. Это не переход к мировой 3D-модели DWG. Внешняя CAD-печать нового TOP пока не подтверждена.

10 новых проверок TOP + 7 стыковки, общий пакет 114 PASS. Визуальная приёмка ожидает запуска локального сервера пользователем; не подтверждена тестами функций.
