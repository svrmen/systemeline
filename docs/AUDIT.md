# Аудит конфигуратора SystemeLine B

Дата: 2026-10-04. Проверено: index.html, целевые тесты, сохранение, код экспорта и тарифов, локальный браузер; извлечённые данные каталога2026 и руководства. Это аудит с исправлениями критичных UI-дефектов, не полная инженерная приёмка.

## Сценарии и результат
1. Создание выноски — до исправления редактор уходил за край (evidence/audit/01-callout-before.png). После исправления: редактор ограничен окном; создание больше не открывает одновременно длину.
2. Перенос текста — PASS в браузере: обычное перетаскивание, линия до края карточки, положение сохраняется после reload (evidence/audit/03-callout-after.png). Точка переносится отдельным маркером; двойной щелчок/карандаш редактируют текст. Это выноска конкретного вида, не привязка к 3D-объекту.
3. Восстановление — исправлены повторные ID, сохранение в процессе загрузки, потеря отключённых креплений и выбор номинала. Браузер подтвердил сохранение текущей трассы/ориентации/выноски; все старые варианты проектов отдельно не проверены.
4. Стоимость — неизвестная цена теперь «—», итог не определён. Старые тарифы IP55 не применяются к IP65. Парсер текстовых строк был пустым: отключён до получения тарифа.
5. Размеры/навигация — предыдущий этап: габариты Cu, LF/LE, положение на ребро, DPR, ограничения pan/zoom; целевые проверки сохранены. Все сочетания токов/материалов/маршрутов визуально не проверены.
6. Экспорт — код просмотрен; прежняя проверка PNG сохранена. Полная приёмка PDF в печати, XLS в Excel, DXF в CAD не выполнена.

### Почему при3500мм нет промежуточного блока
3500 — осевой размер с плечами углов, а3000 — предел прямой секции. В контрольном Cu4000 EDGE:3500−320−450=2730мм, одна прямая секция; промежуточный стык не нужен. Два стыка с поворотами теперь отображаются. При FLAT плечи следует брать из таблиц текущего номинала, а не переносить2730 на любой случай.
