# Несколько трасс

1. Обновите страницу. Существующий шинопровод станет «Трасса 1»; задайте ему имя, например «ТР1 → НКУ1».
2. Нажмите «Копия трассы», если второй шинопровод похож на первый. Переименуйте в «ТР2 → НКУ2», измените нужные параметры и координаты X/Y/Z. Копия смещена на 4000 мм по Y, её выноски создаются отдельно.
3. Для нового пути без участков выберите «ТР → НКУ» и «Добавить трассу», затем стройте его обычными стрелками.
4. Чтобы построить связь, выберите «НКУ → НКУ» и «Добавить трассу». При наличии двух непустых трасс с концом «ГРЩ» новый путь соединит их конечные точки. Используются первые две такие трассы в списке.
5. Нажмите «Рассчитать все трассы». Выберите «Все трассы» в спецификации и «Показывать все трассы» для общего рисунка.

Параметры, длины и выноски редактируются у трассы, выбранной в списке. По умолчанию показаны только её размеры; «Размеры всех трасс» включает остальные. Исходный стиль рисунка сохранён.

X/Y/Z задают нижний угол оборудования в начале трассы в общей системе координат, в миллиметрах. Изменение этих координат перемещает всю трассу вместе с её выносками. Координаты связи НКУ фиксируются при создании: после перемещения или изменения исходных трасс связь нужно скорректировать. Исполнение и путь следует проверить отдельно; электрическая совместимость и пересечения автоматически не проверяются.

Общая калькуляция объединяет одинаковые артикулы с одинаковой единицей. XLSX содержит лист «Трассы» и раскрой с принадлежностью каждой детали; PDF — таблицу трасс и общий рисунок; CAD — атрибуты каждой трассы. PNG и DXF экспортируют показанные трассы, XLSX/PDF/CSV — выбранную область спецификации. Для экспорта спецификации рассчитайте все непустые трассы области.

«Очистить трассу» очищает выбранную трассу, сохраняя остальные и общие данные. Старый одиночный проект переносится автоматически, оригинальное сохранение остаётся отдельно.

Спецификация остаётся предварительной: реальные FE/FET и их длины, вертикальные и строительные опоры, монтажная комплектность IP требуют подтверждения исходными данными.
